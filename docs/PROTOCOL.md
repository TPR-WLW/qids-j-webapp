# 計測プロトコル / SOP（収集・リクルート）

[`ml/PREREGISTRATION.md`](../ml/PREREGISTRATION.md) と対。**確認データ収集の手順を標準化**し、交絡とノイズを抑える。
データは一回性で取り直せないため、ここを固定してから集める。

---

## 1. リクルート・サンプル（最優先）

- **陽性が地基**: 健康者のみだと臨床的有意（PHQ-9≥10 / QIDS-J≥11）はまず揃わない（探索は10名中2名）。
  → **臨床/高スコア群を意図的に募集**、または大規模スクリーニングで富化。
- **目標 N**: 各クラス最低 **30**（確定前に検出力計算で更新）。
- **交絡を割る**: 探索で **年齢が支配的交絡**、かつ全員男性。
  → 年齢・性別を**バランス or マッチング**。**女性を必ず含める**。陽性に若年・陰性に高齢も入れて年齢×ラベルの共線を崩す。
- **重測**: 同一被験者の複数回は可（信頼性用）。ただし評価は必ず**被験者単位分割（LOSO）**。

## 2. 適格基準

- **包含**: 同意可能・課題遂行可能な成人。
- **除外/記録**: 不整脈・ペースメーカー（除外）。**β遮断薬・抗コリン薬・向精神薬**（HR/HRV へ影響、記録し感度分析）。妊娠（記録）。

## 3. 標準化条件（交絡を抑える）

| 項目 | 規定 |
|---|---|
| 時間帯 | 固定（例: 午前のみ）。昼夜の HRV 差を避ける |
| 体位 | 座位・背もたれ統一・静室・私語/スマホ禁止 |
| 前処置 | カフェイン前2h・激しい運動前1h・喫煙/食事前1h を禁止 |
| カメラ | 正面・距離/高さ固定・安定照明（逆光/フリッカ回避） |
| 室温 | 記録（末梢血流/HRV に影響） |

## 4. センサー装着 + 品質ゲート

1. **ECG（myBeat）**: 電極を [`assets/ecg-pad-placement.png`](../assets/ecg-pad-placement.png) の位置に貼付 → 電源 ON。
2. **開始前に必ず無線受信テスト**（イントロ右上）: HR/受信が**生理的に妥当**であることを確認してから回答開始。
   - 受信不良・HR 非現実値なら貼り直し（探索初期は RMSSD 数百ms の伪迹が頻発した）。
3. **カメラ**: 顔が枠の中央・全体が映る距離。被験者 ID は**ローマ字推奨**（漢字はファイル名が壊れる）。

## 5. セッション手順（アプリが誘導）

被験者情報 → 同意 → **安静時測定（前）3分・注視十字** → 質問回答 → **安静時測定（後）3分** → 結果・自動保存。
- 安静中は**画面中央を見つめ、リラックスし、大きく動かない**（後安静で動きが増えがち＝要再周知）。

## 6. セッション「合格」判定（解析前に適用）

`ml/build_dataset.py` の QC 列で判定し、不合格は除外：
- ECG: HRV が生理的に妥当 & 拍数下限（`usable_for_ecg_ml=1`）。
- 顔: 全相位で追跡率 ≥ 0.8。
- 安静相位が規定長を満たす。

## 7. データ管理・倫理

- 命名 `<id>_<survey>_<timestamp>`。`data/` はローカルのみ（git 管理外）。バックアップを別途。
- 匿名化 ID、同意取得、**IRB/倫理審査**（特に自殺項目）。
- プロトコル版・装置・収集条件を `session.json` / 別紙に記録（新旧データを混ぜない）。

---

## 収集→解析の流れ

1. 本 SOP で収集 → 2. `extract_faces.py` で顔抽出 → 3. `build_dataset.py` で特徴表 + QC →
4. N・クラス・品質が揃ったら [`PREREGISTRATION.md`](../ml/PREREGISTRATION.md) の**確認的検定のみ**を実行（事後の特徴選択は禁止）。
